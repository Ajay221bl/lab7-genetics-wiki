The table is a pre-computed answer to: 'How big does χ² get by luck alone, 95% of the time?' Row = how many free categories (df); column = how strict you are (α).

## Steps

1. Find your df row.
2. Go across to the α = 0.05 column (always 0.05 in this lab).
3. Read the number.

| df | α = 0.05 |
|---|---|
| 1 | **3.841** |
| 2 | 5.991 |
| 3 | **7.815** |
| 4 | 9.488 |

Common mistake: using 3.841 for ear 5. Ear 5 has df 3 → 7.815.
