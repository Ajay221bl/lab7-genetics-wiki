H = smooth (starchy, dominant), h = wrinkled (sugary).

**HH × hh → F₁**: all Hh, 100% smooth.

**Hh × Hh → F₂ (Corn Ear 3)**:

| | H | h |
|---|---|---|
| **H** | HH | Hh |
| **h** | Hh | hh |

- Genotypes: 25% HH, 50% Hh, 25% hh
- Phenotypes: 75% smooth, 25% wrinkled

| Phenotype | Actual count | Expected # |
|---|---|---|
| Smooth | 145 | 150 |
| Wrinkled | 55 | 50 |

Optional extra practice: χ² = 25/150 + 25/50 = 0.667 < 3.841 → fits 3 : 1.
