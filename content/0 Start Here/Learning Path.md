This is the main road through the wiki. Each stage only uses ideas from the stages before it, so if something feels hard, step back a stage. Tick the box when you can explain the note out loud without looking.

How to read any note: read it once, close it, then explain the idea in plain words as if to a curious 12-year-old. Where you stumble is where the gap is; follow that link. Then answer the **Try it yourself** question at the bottom.
