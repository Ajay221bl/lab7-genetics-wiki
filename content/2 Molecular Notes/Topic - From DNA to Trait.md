> [!abstract] The big question
> How does a chemical inside a cell decide whether a corn kernel is purple or yellow?

## The story in plain words

Imagine a kitchen. There's a cookbook ([[DNA]]) split into volumes ([[Chromosome|chromosomes]]). One recipe in it ([[Gene|a gene]]) says how to build a little machine, an [[Enzyme|enzyme]], that turns a colorless chemical into purple paint ([[Pigment|pigment]]). The cook follows the recipe, builds the machine ([[Protein|protein]]), the machine makes the paint, and the kernel turns purple. That visible result is the [[Phenotype|phenotype]].

Now suppose that, long ago, a typo ([[Mutation|mutation]]) crept into one copy of the recipe. The machine it builds doesn't work. That misprinted recipe is a different version of the gene: a different [[Allele|allele]] (r instead of R).

Each kernel has **two** copies of the cookbook, one from each parent ([[Diploid|diploid]]), so it has two copies of the recipe, at the same page ([[Locus|locus]]) in each volume. The pair of versions it has is its [[Genotype|genotype]] (RR, Rr or rr).

## Build it in order

1. [[DNA]] → [[Chromosome]] → [[Gene]] → [[Locus]]
2. [[Mutation]] → [[Allele]]
3. [[Protein]] → [[Enzyme]] → [[Pigment]] / [[Chlorophyll]]
4. [[Trait]] → [[Genotype]] → [[Phenotype]]
5. [[Diploid]] → [[Homologous Chromosomes]]

## Why it matters for Lab 7

Everything you count (green/albino, purple/yellow, smooth/wrinkled) is a phenotype produced by this chain. You count phenotypes to work backwards to genotypes, and from genotypes to parents.

> [!question]- Check yourself: Explain to a friend, without jargon, why a kernel with one R and one r is still purple.
> **Answer:** One good recipe copy still builds enough paint-making machines to color the kernel fully. See [[Topic - Why Dominance Happens]].
