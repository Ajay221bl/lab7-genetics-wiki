A test cross uses an aa partner because aa can only give a, so it adds nothing that hides the mystery parent's alleles; every offspring's phenotype directly shows which allele came from the mystery parent.

A purple kernel could be RR or Rr; you can't tell by looking. Cross it with rr (yellow):

- If RR: every offspring gets R → all purple.
- If Rr: half get R, half get r → 1 purple : 1 yellow.

The rr partner is like a blank sheet of paper: whatever shows up on it was written by the mystery parent. Using RR as the partner would hide everything, because every offspring would get an R from it.

*A purple parent crossed with yellow (rr): all purple means RR; half yellow means Rr.*

Try it yourself. Ear 2 is about 1:1 purple:yellow. What was the purple parent? Rr.
