Ear 5 uses a higher critical value (7.815) because it has four phenotype categories, so df = 3, and more categories give chance more room to raise χ².

Ears 1-3 have two categories (df 1, bar 3.841). Ears 4 and 5 have four (df 3, bar 7.815). Using 3.841 for ear 5 would set the bar too low and you'd reject true hypotheses far too often.

Try it yourself. Ear 5's sample χ² is 0.376. Decision? 0.376 < 7.815: fail to reject; it fits 9:3:3:1.
