> [!abstract] The big question
> If I know the parents, what fraction of their children should have each genotype and phenotype?

## The story in plain words

A [[Punnett Square|Punnett square]] is a multiplication table for luck. Each parent's possible [[Gamete|gametes]] go on the outside. Because every egg is equally likely to meet every sperm, every box is equally likely. So counting boxes **is** calculating probability.

Recipe:
1. Write the [[Cross|cross]] (Rr × Rr).
2. List each parent's gametes ([[Calc 02 - Writing Gametes]]).
3. Fill the boxes ([[Calc 03 - Filling a Monohybrid Punnett Square]]).
4. Count genotypes → [[Genotype Frequency]], [[Genotypic Ratio]].
5. Group by appearance → [[Phenotype Frequency]], [[Phenotypic Ratio]].
6. Convert fractions to percents ([[Calc 01 - Fraction Decimal Percent]]).

Important (manual p. 122): these are **[[Probability|probabilities]]**, not promises. Real families and real ears wobble.

## Ratios worth memorizing (but understand why)

| Cross | Phenotypes |
|---|---|
| Rr × Rr | [[3-1 Ratio]] (genotypes [[1-2-1 Ratio]]) |
| Rr × rr | [[1-1 Ratio]] |
| RR × anything | all dominant |
| RrHh × RrHh | [[9-3-3-1 Ratio]] |
| RrHh × rrhh | [[1-1-1-1 Ratio]] |

## Build it in order

[[Cross]] → [[P Generation]] → [[F1 Generation]] → [[F2 Generation]] → [[Punnett Square]] → [[Genotype Frequency]] → [[Phenotype Frequency]] → [[Genotypic Ratio]] → [[Phenotypic Ratio]] → [[Monohybrid Cross]] → [[Test Cross]] → [[Dihybrid Cross]] → [[FOIL Method]] → [[Pedigree]]

> [!question]- Check yourself: Why is every box in a Punnett square equally likely?
> **Answer:** Each parent makes each gamete type in equal numbers (meiosis), and fertilization pairs them at random.
