> [!abstract] In one sentence
> A 'retained H₀' is the manual's phrase (p. 124) for a null hypothesis that was not rejected: the data are not at odds with the model.

> [!example] Explain it like I'm new (the Feynman way)
> 'Retained' = we keep H₀ for now.

## Build it from first principles

It means exactly the same as [[Fail to Reject the Null Hypothesis|fail to reject H₀]].

> [!question]- Test yourself: Same as which phrase?
> **Answer:** Fail to reject H₀.
