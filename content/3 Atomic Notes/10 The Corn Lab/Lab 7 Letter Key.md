The Lab 7 letter key: G/g = green/albino seedlings; R/r = purple/yellow kernels; H/h = smooth (starchy)/wrinkled (sugary) kernels.

| Letter | Gene | Meaning |
|---|---|---|
| G | seedling color | green (dominant) |
| g | | albino (recessive) |
| R | kernel color | purple (dominant) |
| r | | yellow (recessive) |
| H | kernel shape | smooth, starchy (dominant) |
| h | | wrinkled, sugary (recessive) |

The trap: pea problems reuse letters differently (D/d purple/white flowers, H/h tall/short), and the slides use B/b and R/r for other traits. A letter means only what that problem says.

Try it yourself. What does h mean on ear 3? The wrinkled (sugary) kernel allele.
