> [!abstract] In one sentence
> The Lab 7 letter key: G/g = green/albino seedlings; R/r = purple/yellow kernels; H/h = smooth (starchy)/wrinkled (sugary) kernels.

> [!example] Explain it like I'm new (the Feynman way)
> A legend for the lab's map.

## Build it from first principles

| Letter | Gene | Meaning |
|---|---|---|
| G | seedling color | green (dominant) |
| g | | albino (recessive) |
| R | kernel color | purple (dominant) |
| r | | yellow (recessive) |
| H | kernel shape | smooth, starchy (dominant) |
| h | | wrinkled, sugary (recessive) |

Pea practice problems reuse letters differently: D/d purple/white flowers, H/h tall/short. Slides: B/b eye color, R/r red/white flowers (slide 8). A letter means only what that problem says.

> [!question]- Test yourself: What does h mean on ear 3?
> **Answer:** Wrinkled (sugary) kernel allele.
