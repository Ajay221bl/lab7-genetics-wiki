A cross is a planned mating between two individuals; "Gg × gg" is read "Gg crossed with gg".

Every genetics problem starts the same way: write the cross, then work out each parent's [[Gamete|gametes]], then combine them in a [[Punnett Square|Punnett square]].

For autosomal genes, order doesn't matter: Gg × gg gives the same offspring as gg × Gg. For X-linked genes it does, because mothers and fathers pass different sex chromosomes.

Try it yourself. Read "RrHh × rrhh" out loud. "Double heterozygote crossed with double homozygous recessive."
