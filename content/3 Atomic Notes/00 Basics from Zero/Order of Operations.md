When a formula has several steps, do brackets first, then powers (squares), then multiplication and division, then addition and subtraction.

The chi-square formula is a perfect example: (O − E)² / E.

1. **Brackets first:** O − E.
2. **Then the power:** square that gap.
3. **Then divide** by E.
4. Finally the Σ says **add** across categories.

If you do it in a different order you get a different number. (18 − 17.25)² / 17.25 = 0.033. But if you squared first, 18² − 17.25² = 26.4, you'd be miles off.

This is exactly why the manual's table has one column per step. The columns *are* the order of operations, written out so you can't skip ahead.

Try it yourself. Compute (5 − 5.75)² / 5.75. Brackets: −0.75. Square: 0.5625. Divide: 0.098.
